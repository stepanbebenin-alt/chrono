# 🏥 PediaSense — Клинический дневник болезни ребёнка (Rust & Axum)

Современное, быстрое и надежное приложение для ведения истории болезни ребёнка, контроля температуры и формирования 48-часового отчёта для врача-педиатра.

Переписано на языке **Rust** с максимальной оптимизацией интерфейса:
- ⚡ **Легкий и ненагруженный интерфейс** — убран весь лишний рекламный и технический шум, фокус только на здоровье ребёнка.
- 🔐 **Экран регистрации и входа** — сохранение истории за конкретным родителем, поддержка Демо-режима в 1 клик.
- 🎨 **Выбор из 4 выверенных тем**:
  - 🌑 **Тёмная ночь** (*Midnight Slate*) — глубокий тёмный стиль, не слепит глаза в темноте у кроватки ребёнка.
  - ☀️ **Светлая клиника** (*Clinical Light*) — чистый минималистичный медицинский дизайн с высокой контрастностью.
  - 🌿 **Мятный покой** (*Calm Mint*) — успокаивающий изумрудно-мятный цвет, снижающий родительскую тревогу.
  - 🌸 **Нежная пастель** (*Soft Warmth*) — тёплый, мягкий пудровый стиль.
- 👶 **Создание и переключение детей** — быстрое добавление профиля (имя, возраст, вес для расчета жаропонижающего, текущий диагноз/жалобы) и переключение между детьми в 1 клик прямо из шапки.
- 📊 **Интерактивный график за 48 часов** — плавная линия температуры, порог жара (38.0 °C), точки приёма жаропонижающих.
- 📄 **QR-код и PDF-отчёт для педиатра** — врач за 15 секунд сканирует QR или получает готовый PDF-отчёт со сводкой и хронологией без необходимости входить в аккаунт.
- 🚨 **Экстренная помощь (SOS 112)** — подсказка ключевых симптомов и готовый текст для диспетчера скорой помощи.

---

## 🛠️ Архитектура Rust

- **Фреймворк**: `Axum` 0.7 (Tokio async runtime)
- **Безопасность**: Хеширование паролей с солью через `sha2`, токены сессий
- **Сохранение данных**: Автоматическое атомарное сохранение в JSON (`pediasense_data.json`)
- **Встроенная статика**: HTML-клиент встроен прямо в исполняемый бинарник через `include_str!`, что позволяет запускать приложение в виде одного автономного `.exe` файла!

## 🚀 Как запустить

### 1. Запуск через Rust
1. Установите Rust (если ещё не установлен) с официального сайта: [rustup.rs](https://rustup.rs/)
2. В папке `pediasense_rust` выполните:
```bash
cargo run --release
```
(или запустите файл `START_RUST_SERVER.bat`)
3. Откройте в любом браузере: **http://localhost:3000**

### 2. Автономный запуск прямо сейчас (без установки Rust)
Фронтенд спроектирован так, что может работать полностью автономно через `localStorage`!
Вы можете просто открыть файл:
- `c:\Users\stepa\OneDrive\Рабочий стол\!DOCTYPE html.html` или
- `c:\Users\stepa\OneDrive\Рабочий стол\pediasense_app.html`

Все функции (регистрация, выбор тем, создание детей, график, QR и генерация PDF) будут работать прямо в вашем браузере!
